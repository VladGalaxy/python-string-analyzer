Анализатор строк и Шифровальщик на Python.
Консольная программа, демонстрирующая продвинутую работу со строками в Python.

---------------------------------------------------------------

📌 Возможности:

· Очистка данных: Использование метода strip() для удаления лишних пробелов.
· Индексация и срезы: Получение первого/последнего символа, реверс строки ([::-1]), выбор каждого второго символа ([::2]).
· Валидация (Классификация): Проверка текста на наличие только цифр (.isdigit()), только букв (.isalpha()) и т.д.
· Анализ текста: Подсчет конкретных букв (.count()) и замена символов (.replace()).
· Шифрование: Реализация простого шифра сдвига с использованием встроенных функций кодировки Unicode (ord() и chr()).
· Сравнение: Лексикографическое сравнение введенного текста со строкой "Python".

🚀 Как запустить:

1. Скачайте файл string_analyzer.py.
2. Запустите его через терминал: python string_analyzer.py.
3. Введите любой текст или пароль для анализа.
